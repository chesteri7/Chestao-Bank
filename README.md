# Sistema Chestão

Um sistema web de gerenciamento de empréstimos desenvolvido com HTML, CSS e JavaScript.

## Características

- ✅ Autenticação de usuários com login
- ✅ Gerenciamento de clientes
- ✅ Controle de empréstimos
- ✅ Visualização de lista de empréstimos
- ✅ Interface responsiva

## Estrutura do Projeto

```
emprestimos/
├── index.html              # Página principal
├── login.html              # Página de login
├── login.css               # Estilos do login
├── clientes.html           # Gerenciamento de clientes
├── clientes.css            # Estilos de clientes
├── clientes.js             # Lógica de clientes
├── emprestimos.html        # Formulário de empréstimos
├── emprestimos.css         # Estilos de empréstimos
├── emprestimos.js          # Lógica de empréstimos
├── emprestimos-lista.html  # Lista de empréstimos
├── emprestimos-lista.css   # Estilos da lista
├── emprestimos-lista.js    # Lógica da lista
├── scripts.js              # Scripts globais
└── assets/                 # Arquivos de mídia
```

## Como Usar

1. Abra o arquivo `index.html` no seu navegador
2. Faça login com suas credenciais
3. Navegue pelas seções de clientes e empréstimos
4. Adicione, edite ou visualize informações conforme necessário

## Tecnologias Utilizadas

- **HTML5** - Estrutura das páginas
- **CSS3** - Estilos e layout
- **JavaScript** - Lógica e interatividade

## Requisitos

- Navegador moderno (Chrome, Firefox, Edge, Safari)
- Sem dependências externas
