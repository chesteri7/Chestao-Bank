# Chestão Bank

Sistema web para gerenciamento de clientes, empréstimos, parcelas, pagamentos e comprovantes.

## Funcionalidades

- Cadastro de clientes
- Cadastro de empréstimos
- Controle de parcelas
- Status de pagamento
- Dashboard financeiro
- Upload e visualização de comprovantes
- Filtros por cliente, status e data

## Tecnologias

- HTML
- CSS
- JavaScript
- Node.js
- Express
- PostgreSQL
- Multer
- JWT
